What is an Audit Trail?

An audit trail is a chronological record of all user activities, system events, and data changes that occur within an application.

Key Components:

📅 Timestamp

When the action occurred (UTC recommended)

👤 User Identity

Who performed the action

🎯 Action Type

What action was performed

📍 Resource

What was affected

📊 Before/After

State changes (if applicable)

🌐 Context

IP address, session info, etc.

Implementation: Audit Models & Interfaces

// audit.models.ts export interface AuditEntry { id: string; timestamp: string; userId: string; sessionId?: string; action: AuditActionType; resource: string; resourceId?: string; oldValue?: any; newValue?: any; details?: Record<string, any>; ipAddress?: string; userAgent?: string; location?: string; success: boolean; errorMessage?: string; } export enum AuditActionType { CREATE = 'CREATE', READ = 'READ', UPDATE = 'UPDATE', DELETE = 'DELETE', LOGIN = 'LOGIN', LOGOUT = 'LOGOUT', EXPORT = 'EXPORT', PRINT = 'PRINT', SEARCH = 'SEARCH', DOWNLOAD = 'DOWNLOAD' } export interface AuditAction { type: AuditActionType; resource: string; resourceId?: string; details?: Record<string, any>; oldValue?: any; newValue?: any; }

HTTP Interceptor for Automatic Logging

// audit-interceptor.ts @Injectable() export class AuditInterceptor implements HttpInterceptor { constructor(private auditService: AuditService) {} intercept(req: HttpRequest<any>, next: HttpHandler): Observable<HttpEvent<any>> { const startTime = Date.now(); return next.handle(req).pipe( tap({ next: (event) => { if (event instanceof HttpResponse) { this.logHttpSuccess(req, event, startTime); } }, error: (error) => { this.logHttpError(req, error, startTime); } }) ); } private logHttpSuccess(req: HttpRequest<any>, res: HttpResponse<any>, startTime: number): void { if (this.shouldAudit(req)) { const action: AuditAction = { type: this.mapHttpMethodToAction(req.method), resource: this.extractResource(req.url), details: { method: req.method, url: req.url, statusCode: res.status, responseTime: Date.now() - startTime, requestBody: this.sanitizeBody(req.body) } }; this.auditService.logAction(action); } } }

Component-Level Audit Logging

// user-profile.component.ts @Component({ selector: 'app-user-profile', templateUrl: './user-profile.component.html' }) export class UserProfileComponent implements OnInit { constructor(private auditService: AuditService) {} ngOnInit(): void { // Log page view this.auditService.logAction({ type: AuditActionType.READ, resource: 'user-profile', details: { page: 'profile-view' } }); } updateProfile(profileData: UserProfile): void { const oldValue = { ...this.currentProfile }; this.userService.updateProfile(profileData).subscribe({ next: (updatedProfile) => { // Log successful update this.auditService.logAction({ type: AuditActionType.UPDATE, resource: 'user-profile', resourceId: updatedProfile.id, oldValue: oldValue, newValue: updatedProfile, details: { fieldsChanged: this.getChangedFields(oldValue, updatedProfile) } }); }, error: (error) => { // Log failed update this.auditService.logAction({ type: AuditActionType.UPDATE, resource: 'user-profile', details: { error: error.message, success: false } }); } }); } }

Security Best Practices

⚠️ Critical Security Considerations

🔐 Data Sanitization

• Never log passwords or sensitive data
• Mask PII (personally identifiable information)
• Hash sensitive identifiers

🛡️ Access Control

• Restrict audit log access
• Role-based permissions
• Audit the auditors

🔒 Encryption

• Encrypt audit data in transit
• Encrypt stored audit logs
• Use HTTPS for all communications

📝 Integrity

• Prevent audit log tampering
• Use checksums or digital signatures
• Immutable storage solutions
// Data sanitization example private sanitizeAuditData(data: any): any { const sensitiveFields = ['password', 'ssn', 'creditCard', 'token']; return this.deepClone(data, (key, value) => { if (sensitiveFields.includes(key.toLowerCase())) { return '[REDACTED]'; } if (typeof value === 'string' && this.looksLikeEmail(value)) { return this.maskEmail(value); } return value; }); }

Performance Optimization Strategies

🚀 Batching & Queuing

// Optimized batching implementation private processBatch(): void { if (this.auditQueue.length === 0) return; const batch = this.auditQueue.splice(0, this.batchSize); const compressedBatch = this.compressAuditData(batch); this.http.post('/api/audit/batch', compressedBatch, { headers: { 'Content-Encoding': 'gzip' } }).subscribe({ next: () => console.log(`Sent ${batch.length} audit entries`), error: (error) => { // Re-queue failed entries this.auditQueue.unshift(...batch); console.error('Failed to send audit batch:', error); } }); }

📦 Compression

Use gzip compression for large audit payloads

⏱️ Debouncing

Debounce rapid successive actions

🎯 Selective Logging

Only log business-critical events

🔄 Background Processing

Use Web Workers for heavy processing

Common Pitfalls & Solutions

❌ Common Pitfalls

Over-logging

Logging every single user action creates noise and performance issues

Inconsistent Format

Different log formats make analysis difficult

Missing Context

Insufficient information to understand actions

Security Oversights

Logging sensitive data or inadequate access controls

✅ Solutions

Strategic Logging

Focus on business-critical events and user journeys

Standardized Schema

Use consistent audit entry structure across the application

Rich Metadata

Include session, user context, and business context

Security by Design

Implement data sanitization and access controls from the start

Real-world Example: E-commerce Application

// order.component.ts - Complete audit implementation export class OrderComponent { async placeOrder(orderData: OrderRequest): Promise<void> { const auditContext = { orderId: this.generateOrderId(), customerId: this.authService.getCurrentUserId(), totalAmount: orderData.total, itemCount: orderData.items.length }; try { // Log order initiation this.auditService.logAction({ type: AuditActionType.CREATE, resource: 'order', resourceId: auditContext.orderId, details: { ...auditContext, stage: 'initiated', paymentMethod: orderData.paymentMethod } }); const order = await this.orderService.createOrder(orderData).toPromise(); // Log successful order creation this.auditService.logAction({ type: AuditActionType.CREATE, resource: 'order', resourceId: order.id, newValue: order, details: { ...auditContext, stage: 'completed', confirmationNumber: order.confirmationNumber } }); } catch (error) { // Log order failure this.auditService.logAction({ type: AuditActionType.CREATE, resource: 'order', details: { ...auditContext, stage: 'failed', error: error.message, success: false } }); throw error; } } }
